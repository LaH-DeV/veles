Open design notes — the user's own, plus open questions raised while building.
Only what is still open lives here; numbering is historical. When an item is
done its record goes to the progress log, and the item leaves this file.
Everything that was here up to 2026-09-27, done items included, is kept
verbatim in archive/notes-history.txt. Lines starting with `→` are status
notes, not the user's text.

=== 2026-09-28 (user) ===

* we should be on track to self-hosting, slowly but surely, not yet writing Veles compiler, but ensuring we're going towards it.
* every feature must be complete, performant, manageable on 'lower level' but with the highest possible devex for higher level usage.
* we'll be using WSL for Linux (it is installed), and we'll be self-running it on macos (m4), but later.
   → Self-hosting readiness is track S in veles-plan.md; the two principles lead the plan.
   → WSL: Linux done 2026-09-28 (plan A1; the whole suite and the thread stress green,
     `internal/wsl-test.sh` reruns it). macOS M4 is A7.

=== Standing directions ===

R3. Platforms: Windows is the test platform now; Linux next, then macOS — every runtime binding
    must work on all three. Windows text bindings (args, env, cwd, listDir, file paths) must go
    through the wide (UTF-16) APIs so non-ASCII names stay valid UTF-8 (D18).
    → Linux x86-64 green since 2026-09-28 (plan A1). macOS not yet (A7).

R5. Examples (small and mid-size) must DO something useful — real use cases, not demonstrations
    of syntax: a tool someone would run (todo CLI, log analyser, file dedup, ...).

   LATER (user, 2026-09-18): plan a real std library — algorithms, json, collections beyond
   these, text formatting, etc. — "efficient, optimized and safe"; NOT before the language is
   stable. For now examples/ is where such code lives and gets exercised.

=== Open ===

5. I hate `Some(null)` and other Some and Ok and Err... this is rust.. WHY
   (partly: `is Ok` / `is Err` now smart-cast to the payload, so Ok/Err are rarely spelled)
   → Also since: `r.ok` / `r.err`, `when (val r = ...) { is Ok => r }`, let-else
     (`val x = r else { ... }`) and `r ?? fallback` (D61). What is still spelled: `Some(x)`
     and `Ok(v)` / `Err(e)` patterns when a payload is destructured.
