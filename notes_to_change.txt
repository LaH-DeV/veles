=== 2026-10-05 (review of `const fun`, D113 part 3; requested by the user, written by us) ===

C1. Do better in the compiler (order = what matters most to users):
    a. Function values in a `const fun` (lambdas, closures, trait objects): today `map`, `filter`,
       `sortedBy`, `fold` and every callback-taking std function are unusable. The self-hosted
       lexer's tables would want them.
    b. `throws` / `try` / `catch` inside a `const fun` (spec allows it: a thrown error is a
       compile error at the constant).
    c. Std coverage is silent: a user learns a std function is not `const` from the error.
       Mark systematically (List/Map/Range/iterator helpers, Duration, hex/base64/utf8) and add a
       test that lists the const std functions so coverage cannot regress unnoticed.
    d. Derived `equals`/`hash`/`toString`/`compareTo` should be `const` (lifts "custom hash/equals
       keys refused" for constant maps).
    e. libm floats (`sin`, `exp`, `log`, `pow`…) are not evaluated: build a correctly rounded
       software version, or decide that results may differ. Needs the user (veles-decide).
    f. Speed: ~6 M steps/s (map per call frame); slots instead of maps for Unicode-table sized work.
       Generic `const fun` bodies are validated per instance only (an unused generic can hide an
       invalid body).
    g. Diagnostics: HIR nodes carry no spans, so declaration-time errors (global read, lambda) point
       at the function name; "calls `$init`" and derived-function messages read poorly.
    h. Tooling: show the computed value of a constant on hover (not only some cases); a
       `--const-stats` report of steps per constant; `tryConst` runs no function, so `TABLE.at(f())`
       is not read at compile time.
    i. Review each std function marked `const` by script (StringBuilder, string methods, number
       compareTo/toString) for semantics beyond what the differential test covers.

   → Items 1.a–1.d, 1.f–1.h and part of 1.e are also in veles-checklist.md §11 "Deferred from
     `const fun`"; this block is the review list, to be worked through.
